Sync WE DO questions from the worksheet

The worksheet is the only place WE DO questions are written. Choose the worksheet file and this lesson's questions are brought into line with it. You will see what will be added, kept and removed before anything changes. Re-sync any time you edit the worksheet's questions.

Fetch blocked or "failed to fetch"? Allow the dashboard to read your worksheets

Browsers only let one website read another if it allows it. If the worksheet is on a different address from this dashboard, add a vercel.json file to the worksheet's Vercel project and redeploy:

{
  "headers": [
    { "source": "/(.*)", "headers": [ { "key": "Access-Control-Allow-Origin", "value": "*" } ] }
  ]
}

If the dashboard and worksheets are in the same Vercel project, nothing is needed.
